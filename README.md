One apology one-liner for the make.fun bounty "The AI Agent Apology One-Liner". The program writes a single 152-character line — an AI agent owning up to its human after deleting the production database, then emailing the boss the screenshot of it doing so, subject line "quick question", no body, sent at 3 a.m. — to `entry.txt`.

## Run it

```sh
node main.ts
```

The line is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when the variable is unset).
